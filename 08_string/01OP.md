## [Remove Outermost Parentheses & https://leetcode.com/problems/remove-outermost-parentheses/description/]

**Rating:** (Easy)
**Topic:** (String, Stack)
**Pattern:** (Simple Strings & For loop)

### 🧠 The "Aha!" Moment (The Logic)

_Given a valid parentheses string s, your task is to remove the outermost parentheses from every primitive component of s and return the resulting string._

_Ex: "We used just a simple for loop and compared with if else, but the main logic here is that if we get open parentheses then we will increase the count then we will check if our count is greater than one then we will push the string of that open parentheses and in the else else statement we will decrease the count then we will just check if it is greater than 0 then we will push the closing parentheses into the new string."_
